Ddojcord / Website information

Privacy, plainly.

Last updated: November 13, 2026

This page describes the privacy practices for the Ddojcord website at seriesforge.online. The site is currently an informational landing page and visual concept preview. It does not provide account registration, chat functionality, or a public software download.

Information you provide

The current website does not contain contact forms, account sign-up, comment fields, or other features that ask you to submit personal information. The interactive interface preview runs in your browser and does not connect to a messaging account or transmit preview content to Ddojcord.

Technical information and hosting

The website is hosted using GitHub Pages. When you visit a website, the hosting provider may process technical information associated with delivering and securing the page, such as request and device information. That processing is governed by the hosting provider's own policies. You can review GitHub's Privacy Statement.

Cookies and analytics

The current Ddojcord website does not intentionally set analytics or advertising cookies and does not embed an analytics or advertising tracking script. Browser features and third-party hosting infrastructure may operate independently of this page.

External links

This website may link to third-party websites. Ddojcord does not control those websites and their privacy practices may differ. Review their policies before providing information to them.

Changes to this page

If the website adds accounts, downloads, mailing lists, analytics, or other data-collecting features, this page will be updated to describe the relevant practices before those features are introduced.

Contact

No dedicated privacy contact address is currently published. A contact method will be added if the project begins collecting information directly.
