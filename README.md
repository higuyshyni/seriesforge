# Ddojcord

Ddojcord is an independent desktop client concept exploring a more personal, modular and immersive chat experience.

The public website is a static GitHub Pages landing page with an interactive visual preview. The preview is not connected to a chat service and does not represent a released client.

## Website

- Domain: https://seriesforge.online
- Hosting: GitHub Pages
- Main page: \`index.html\`
- Styles: \`assets/ddojcord.css\`
- Interactions: \`assets/ddojcord.js\`

Ddojcord is not affiliated with, endorsed by, or sponsored by Discord Inc. Discord is a trademark of Discord Inc.
